## `01` / Engineering Profile

I'm a software engineer interested in the intersection of **geospatial computing, scientific simulation, desktop architecture, and AI engineering**.

My focus is not just making software work — it's building reliable, maintainable systems that connect complex algorithms with practical engineering workflows.

- 🌍 **Geospatial Engineering** — GIS, spatial analysis, urban flood modeling, and hydrological simulation.
- 🏗️ **Software Architecture** — Modular desktop applications, cross-language integration, and scalable service design.
- 🤖 **AI Engineering** — Local LLM deployment, agentic workflows, inference optimization, and speech AI.
- ⚡ **Performance Engineering** — GPU acceleration, computational workloads, resource management, and responsive interfaces.

> **Engineering philosophy:** Build for real-world constraints. Optimize for clarity, reliability, and long-term evolution.
